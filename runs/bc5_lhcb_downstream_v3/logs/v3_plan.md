## 3. 任务 3：把边界处的 MC 误差压到 5%（报告：logs/mc_convergence_v3.md，568 行）

### 3.1 现状（实测，不是估计）

* 长寿命边界：s 的相对 MC 误差 4.7–8.2%（中位 6.6%），θ² 边界误差 3.6–7.1%。
* 短寿命边界：s 的相对误差 29.5–97.3%，但 θ² 边界误差只有中位 7.6%（因为那段是斜率为 5.6–13 的墙）。
* 每质量 1200 个母粒子时全套 52 点扫描实测 **7.9 CPU-分钟**（不是文档里的 20 分钟）。

### 3.2 误差来源（用实验分出来的，不是猜的）

* **有限母样本占 90–97%（长寿命）/ 100%（短寿命）的方差**；等效母粒子数 n_eff 在长寿命端 190–305（共 7200），
  在短寿命端只有 **3–7**——这就是重尾的来源。
* 内层 A(z) 的 ndecay 从 8 提到无穷只值 2–10%（长寿命）、0（短寿命）。**不要动 ndecay。**
* 「一个母粒子只抽一个道、权重取 ΣBR(=3.2–3.4)」的采样贡献 <0.1%。**不要动它。**
* 长寿命端 rel ∝ nsamp^(−1/2) 精确成立；短寿命端只有 nsamp^(−0.16…−0.31)，所以靠加样本压短寿命边界很贵。

### 3.3 结论与代价

| 目标 | 需要的 nsamp | CPU 时间（单线程） | 32 核墙钟 |
|---|---|---|---|
| 现状 1200 统一 | 1200 | 7.9 min | ~0.5 min |
| **长寿命边界全部 5%** | 中位 1200，最大 2433（22/52 点要提高） | **8.6 min** | ~1.5 min |
| 两侧边界都 5% | 中位 1901，最大 25871（7 个质量点 >4800） | 15.0 min（重尾点是下界） | ~5.5 min |

分层重要性采样在长寿命端只能降 1.3–1.7 倍方差（Neyman 分配 4.9 倍），**在短寿命端完全失效**；
确定性求积没有优势（误差 ∝ K^−0.5 而非 K^−2）。所以「自适应」的正确含义是**逐质量分配 nsamp**，
不是换估计量。

顺带发现：生产扫描里 m=0.905 的短寿命点是个 ~2σ 离群点，重跑会变化 1.7–2 倍，那个边界值现在不可信。

### 3.4 建议

1. 逐质量自适应：nsamp = 1200 起步，按上一轮 relerr 迭代到 ≤5%（长寿命边界），7 个墙点（0.905, 2.32, 2.71,
   1.70, 6.96, 0.353, 3.18）单独给 4800–25000；
2. 短寿命边界上的误差改成「跨 3 个母样本种子的散差」而不是单次方差，得到的才是诚实的重尾误差；
3. 若坚持两侧都 5%，唯一有效手段是对 S 的衰变方向做重要性采样（可研，工作量较大）；
4. 可选：把质量循环并行化（多进程，质量之间天然独立），32 核可把墙钟从 ~9 min 压到 ~1.5 min。

## 7. 独立审查响应（2026-10-20 深夜）

外部审查提出 5 条，逐条处理。

### 7.1 局部重扫可能混合不同物理版本 —— 有效，已修

`--only-masses` 之前只保留旧质量点、不校验旧结果的来源，而且用**全精度浮点**做字典键：旧点
`0.48351720691767525` 与重扫时传的 `0.483517` 不相等，会变成新增点（52 → 53），旧点没被替换。
现在：

* 所有质量键统一 `round(m, 6)` 规范化，重扫**必然替换**旧点；
* scan JSON 写入 `model_tag`、`sigma_bb_pb`、`b_yield_corr`；
* 合并前逐项比对，不一致直接 `SystemExit` 报错（除非显式 `--force-mix`）。

### 7.2 B 母样本修正没修干净、修正系数有口径问题和安全隐患 —— 部分有效，已改

* **漏 1.77%**：审查对 B±/B⁰/B_s 的独立统计（新筛选 37,691 vs 全部正状态 38,369）是对的。原因是
  83/84 之外还有 81/82/85/86 里的少量末态 b 强子（我的 20k 诊断给 0.0391/事件，约 2%）。
  **处理**：不再用硬编码系数，改为**从样本文件自身推导**——
  `corr = REF_B_MESON_YIELD / (样本中 B±/B⁰/B_s 行数 / n_gen)`，`REF_B_MESON_YIELD = 1.918`（同一
  生成器的全状态测量值，审查的 1.918 与之相符）。这样漏掉的那 1.8% 会被系数自动吸收。
* **口径不一致**：原 1.466 来自"全部 b 强子"，而分析只用 B±/B⁰/B_s。新方案按**实际使用的三个
  粒子**计数，口径一致。
* **换样本后忘记取消系数的风险**：新方案下系数由文件自动算出——新样本装上后自动变成 1.00 并
  打印 `the sample carries the full b-meson yield; correction is 1.00`，不需要人工改任何常数。
  另外 `b_yield_corr` 写进 scan JSON，模型不一致时合并会被拒绝。

### 7.3 B_s 包容模型超出适用范围 —— 有效，已修

`br_Bs_inclusive()` 现在在 `m_S >= m_Bs - m_phi = 4.347 GeV`（B_s→φS 阈值）处**截断为 0**，
docstring 里直接引 Winkler 原文"not valid close to the kinematic endpoint"以及他对普通 B 介子在
4.7 GeV 以上改用排他道的处理，并说明：该点之上只剩 η/η′ 道，两个文献都没给 B_s→η 形状因子，
所以置零并标记，而不是外推。已验证 `m_S = 4.35/4.5/5.2 GeV` 全部返回 0。

### 7.4 "5% 收敛"混用了两种误差、自适应未闭环 —— 一半有效

* **两种误差**：确实必须分开。`δs/s`（边界处信号量的 MC 误差，prompt.md §3.5 的要求）和
  `δθ²/θ²`（边界位置误差）是不同量，后者在短寿命"墙"上小得多。现在 `run_sensitivity.py` 收尾
  **同时打印两个量**（从 scan JSON 算 `δs/s`，从 `exclusion_boundary.csv` 算 `δθ²/θ²`），不再混用。
* **闭环**：`--adaptive` 本身就是闭环（基础扫描 → 算每个质量点交点处误差 → 按 `(rel/target)²`
