日期：2026-10-25。全程仅写诊断产物和审查文档，未修改生产实现。

## 1. 修正上一份报告的归因强度

原论文第 5.1 节式 (1) 列出 $\epsilon_{\rm rec}\epsilon_{S/B}$，文字给出 0.4 和 0.87。[论文链接](https://link.springer.com/article/10.1140/epjc/s10052-024-12906-3)

但本地 `E:/AAAwork/LLP/code/SensCalc-main/3. Scalar sensitivity.nb` 中，LHCb 的显式效率设置是：

```wolfram
epsilonReco[mLLP_] = If[StringContainsQ[experiment, "LHCb-downstream"], 0.4, ...]
NevInt[...] = quarticBRRescaling * epsilonReco[mLLP] * interpolatedTabulatedYield
```

上面是简化排版，实际符号为 `εreco` 和 `NevInt`。两次出现分别在定义与产额使用处；scalar notebook 中没有 `0.87`，绘图 notebook 中也没有该因子。扫描相关 notebook 的 `0.87` 命中仅来自其他模型的质量网格，不是信号保留效率。此前检查的接受率表和逐道产额结构也没有给出一个已确认的全局 0.87。

因此：**本地核查的 SensCalc scalar 实现未发现额外乘 0.87；不能只根据论文写了该数值就认定原图实际使用了它。** 原图生成时是否有仓库外的重权/不同运行设置，尚无证据。

上一份报告及回答将它称为原图偏差的“确定来源”过强，现已修正文档。原先 0.70 变到 0.80 是反事实/条件检验：如果当前信号统一乘 0.87，就会发生这一变化；它本身不是因果定位。

## 2. 低质量也一定会受到影响

令 $x=\theta^2$。长寿命极限中，固定 $\mathrm{BR}(h\to SS)$ 的 Higgs 道以及由四点耦合产生双 scalar 的介子道近似给出 $s\propto x$；混合诱导的介子单 scalar 道产生率和衰变概率各含一个 $x$，给出 $s\propto x^2$。

所以可以写成：

$$
s\simeq a x+b x^2,
\qquad
p=\frac{d\ln s}{d\ln x},\quad 1\lesssim p\lesssim2.
$$

整体效率乘 $\epsilon$ 后，边界位移近似为 $x_{\rm new}/x_{\rm old}\simeq\epsilon^{-1/p}$。对 0.87，纯混合道极限约上移 7.2%，纯 Higgs 极限约上移 14.9%。低质量不是全都由混合道主导，不能忽略双 scalar 介子道。

直接读取当前 `signal_scan_refbr.json`，统一乘 0.87 后重新求长寿命交点：

| $m_S$ (GeV) | 25 fb$^{-1}$ 边界上移 | 300 fb$^{-1}$ 边界上移 |
|---:|---:|---:|
| 0.302053 | 7.50% | 8.18% |
| 0.483517 | 7.92% | 9.51% |
| 0.774 | 8.68% | 11.49% |
| 1.0 | 11.11% | 14.11% |
| 1.44937 | 9.15% | 12.35% |
| 1.983347 | 9.44% | 12.84% |
| 13.023095 | 15.00% | 14.95% |
| 53.419632 | 14.99% | 14.95% |

因此“低质量看起来接近”并不代表该效率在那里无效。对数图上 7–14% 的移动不显眼，也可能与其他输入差异相互抵消，但是否抵消必须另行验证。**一个统一的 0.87 本身不能产生只在大质量区出现的偏差。**

数值见 `work/physics_review_20261025/efficiency_087_mass_dependence.json`。

## 3. Pythia 端：发现了实际配置错配，但其影响不是当前残差的量级

当前用 `HiggsSM:all = on` 生成未配权的混合母样本，再统一乘 `SIGMA_H_TOTAL`。总率相同不保证各产生道的比例相同。过程代码依据 [Pythia 官方 Higgs 文档](https://pythia.org/latest-manual/HiggsProcesses.html) 判读。

实际 status-62 Higgs 共 197,979 条：

| 类别 | Pythia 样本比例 | 当前代码目标截面对应比例 |
|---|---:|---:|
| ggF，902 | 79.81% | 87.61% |
| VBF，906+907 | 11.09% | 6.82% |
| WH，905 | 3.40% | 2.47% |
| ZH，904 | 1.88% | 1.59% |
| fermion annihilation，901 | 2.74% | bbH 目标约 0.43% |
| ttH，908+909 | 1.08% | 0.91% |

901 是以底夸克为主的费米子湮灭，并非用户要求的 4FS bbH 过程；这里只作为该分量的诊断代理。目标截面中的 tH 等约占 0.17%，样本也没有相应过程代码。以上是可追溯的产生混合与形状近似问题，不是发现 Pythia 引擎本身有错误。

用同一份 Higgs 样本、共同参考接受率、参考 BR 和寿命，在长寿命极限按现有目标截面逐类别重权，结果为：

| $m_S$ (GeV) | 重配权后/当前信号 | 长寿命边界相应变化 |
|---:|---:|---:|
| 5.082255 | 1.00202 | -0.20% |
| 13.023095 | 1.00245 | -0.24% |
| 33.371213 | 1.00326 | -0.33% |
| 53.419632 | 1.00727 | -0.72% |
| 62.49 | 1.01267 | -1.25% |

配对 MC 的信号比标准误差约 0.10–0.12%；不包含参考接受率表、有限库和组内运动学等系统误差。估计权重用的是保留 Higgs 的分组比例，未分别测量每道的生成失败/预筛损失。这是诊断重权，并没有重新生成正确的 4FS bbH 或补 tH。

比例错配值得修正，但这个测试不支持用它解释当前约 30% 的长寿命边偏移。

## 4. 其他已经隔离的 Pythia 相关因素

- 相同 scalar 运动学下，当前衰变响应与现有参考接受率表约差几个百分点；共同质量 62.49 GeV 的 bb 条件库比较，当前/参考为 1.003，当前/2023 公开版本为 0.979，误差约百分之二量级。此结果覆盖有限质量/条件道，不能当成所有 shower 或次级顶点均正确的证明。
- 相同当前衰变响应下，当前 Higgs 产生谱给出的长寿命系数只有参考谱的约 0.76–0.83。替换参考谱会进一步降低边界，作用方向与解释“当前边界低于原图”相反。
- 原 Higgs 角度预筛仍应移除；补回遗漏事件会增加信号，也不能解释当前相对原图的信号增强。
- Higgs 质量差及原图的右端封口影响最后端点，不解释 5–50 GeV 的整体偏移。

当前证据支持：**应继续检查产生和末态的生成设置，但尚未证明 Pythia 是剩余大质量残差的主要原因。0.87 也不能继续作为已证实的原图归因。**
