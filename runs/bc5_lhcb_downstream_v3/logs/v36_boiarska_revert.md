# v3.6：B → X_s S 回到 Boiarska 逐道（2026-10-25）

模型标签 `v3.6-2026-10-25`。这一轮**只改产生过程**，不动宽度、探测器、样本、ε_S/B。

## 1. 为什么改回去

上一轮（v3.4）把 B→X_sS 从 Boiarska 的逐道换成 Winkler 的包容公式，理由是"参考工具 SensCalc 好像
也用包容处方"。核对本地 SensCalc 代码后这个前提不成立：

    (*Exclusive/inclusive production of dark scalar in decays B->Xs+S*)
    SelectedBrChoice="Exclusive";
    PmotherToLLP[mLLP_,θ2_,BrhToSS_,"B-mixing"] = θ2*(fbtob0[Facility]+fbtobplus[Facility])
        * intProd[If[SelectedBrChoice=="Exclusive","BtoXsStotal.dat","BtoXsSinclusive.dat"], ...];

默认 `BtoXsStotal.dat` 就是 Boiarska 的逐道产生率，包容公式只是可切换的备选。prompt.md §3.1 也明确
要求"按 Boiarska 文献逐道纳入…排他道与对应包容率不重复相加"。

## 2. 改了什么（`work/analysis/bc5_production.py`）

| 项 | v3.5（Winkler） | v3.6（Boiarska） |
|---|---|---|
| 运动学耦合 | ξ_sb = 3.786e-4（Winkler eq:effcoupling 用 m_t=173、|V_ts V_tb|） | **ξ_sb = 3.6e-4**（Boiarska Table 2 的列表值）；ξ_ds = 3.3e-6、ξ_db = 7.9e-5 不变 |
| B±/B⁰ → X_s S | eq:inclusive（m_S<4.7 GeV）+ B→Kφ（以上） | **十个 b→s 独占道 + b→d 的 B→π S**（tab:BR），主公式 eq:productionBRmesons |

| B 道动能学 | 无质量回冲（包容）/ K 质量（B→Kφ） | 每道用其衰变末态质量做两体（K、K*、K0*、K1、K2、π） |
| 四点道 | Boiarska Table 4（未变） | 同 |

## 4. 重扫结果（v3.6-2026-10-25，两套扫描都重跑）

MC 验收（F11 口径，按亮度分别）：

| 亮度 | 长寿边 δs/s | >5% | 边界位置误差 δθ²/θ² |
|---|---|---|---|
| 25 fb⁻¹ | 中位 **4.8%**，最大 5.0% | **0/67** | 中位 3.4%，最大 5.0%，**0/134** |
| 300 fb⁻¹ | 中位 **4.7%**，最大 5.0% | **0/67** | 中位 3.4%，最大 5.0%，**0/134** |

验证扫描（参考 BR/宽度表）：同样 0/67；边界位置误差中位 3.6%、6/134 超 5%。

对参考曲线（BC5.pdf 数字化，25 fb⁻¹ 长寿边对下支）：

| 曲线 | 中位比值 | 中位 \|ln\| |
|---|---|---|
| v3.5 生产（Winkler 包容） | 0.839 | 0.384 |
| **v3.6 生产（Boiarska 独占）** | **1.061** | 0.402 |
| **v3.6 验证（参考 BR/宽度）** | **0.955** | **0.217** |

逐段看（v3.6 生产 / 参考）：0.2–1 GeV 0.97–1.18；1–3.5 GeV **1.18–1.98**（低质量鼓起）；
4.3–15 GeV 0.52–0.75；>15 GeV ~0.5–0.6。
换成参考的宽度表（验证扫描）后，低质量段变成 1.0–1.30、4.3–15 GeV 变成 0.60–0.72——即
**1–3.5 GeV 的鼓起主要是宽度模型差异**（我们 Winkler 的 Γ_tot 与参考表在该区间差到 3 倍，
2 GeV 处 6.59e-7 vs 2.03e-7 GeV），不是 B 处方。

## 5. 一个要说明的副作用

B 处方改回独占后，低质量段（1–3.5 GeV）的曲线比"Winkler 包容"版本**更高**（中位 1.15 倍），
也更高于参考曲线。这不是矛盾：参考工具用的就是独占表，但参考**曲线**本身与它的处方不自洽
（本地 SensCalc 曲线只有 PDF 的 0.55–0.62）。我们选"按参考的处方"而不是"贴参考的曲线"。
