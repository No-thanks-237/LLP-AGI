## 2. 衰变宽度（widths）

**已确认正确的部分（勿重开）**：Γ_ll 的 G_F 公式、ππ/KK 的形状因子与 7/9,7/9,2/9 权重、ChPT 形状因子、
gg 的圈函数（与论文 `[x+(x−1)f]/x²` 形式一致到 1e-6）、4π 项的 m³β 与 4m_π 阈值、β³ 与 K/D/B 阈值、
`widths()/gamma_total/ctau_m` 的结构。**m_S < 2 GeV 逐通道与 Winkler 比值 1.0000**（因为强子输入就是他图 3 的数字化）。

**修掉的四个 bug / 三处按论文对齐**：

| # | 问题 | 修前 → 修后 | 验证锚点 |
|---|---|---|---|
| 1 | α_s 的 β 函数系数（2-loop ×2、3-loop ÷2） | α_s(2) 0.3376 → **0.2991** | PDG α_s(m_τ)=0.331、α_s(2)≈0.30、α_s(5)≈0.21 |
| 2 | 夸克质量反常量纲 1-loop 系数 1→2 | m_b(m_Z) 3.35 → **2.886**；m̄_s(10) 0.0761 → 0.0690 | PDG m_b(m_Z)=2.82；Boiarska m̄_s(10)=0.0681 |
| 3 | 光子道用了 α(m_Z) | **α(0)=1/137.036** | Γ(h→γγ)@125.25: 10.99 → **9.578 keV**（参考 9.39）|
| 4 | gg 缺 NLO | 加 Spira 等人的 **K = 1 + (α_s/π)(95/4 − 7/6 n_l)** | Γ(h→gg)@125.25: 0.173 → **0.285 MeV**（NLO 0.286、N3LO 全值 0.337）；K(2)=2.82 |
| 5 | 4π 系数 C（随 gg 的 NLO 重标定） | 5.1e-9 → **1.7227e-8** | 2 GeV 接缝 **1.0000**（原来 +12.8%）；4π 类占 1.99 GeV 的 71%，参考真实 4π 占 74% |

**2 GeV 处理**：Winkler 原文为「m_φ>2 GeV 微扰旁观者模型；m_φ≲1.3 GeV 色散；1.3–2 GeV 用色散结果并加
Γ_{4π,ηη,ρρ,…} = C m³β₂π，取 C 使强子率在 2 GeV 平滑过渡」。我们的结构与此一致，且 `ms <= 2.0` 走色散支
（论文写 "dispersive results up to 2 GeV"）。

## 4. 未做的与已知限制

1. **4π 仍是玩具项**（用户决定暂不改）：C 已按接缝重标定，但通道结构仍是单一 m³β，不是真实的 2π⁺2π⁻ / π⁺π⁻2π⁰ / ηη / ρρ 分解。
2. **Fix 3 未做**：Winkler 的微扰道用固定夸克质量（m_s=95 MeV, m_c=1.3 GeV），我们用 Boiarska 的跑动质量。差异：Γ_ss 在 10 GeV 差 1.56 倍、Γ_S 在 5/10 GeV 差 +20%/+30%（若改固定质量）。两行开关即可切换。
3. **短寿命边**的 MC 重尾未解决；图里 1–2 GeV 的台阶是它的噪声（δθ²/θ² 中位 6.6%、最大 32%）。
4. **1.0 GeV 的 f0(980) 区**：我们 Γ_S 是参考的 0.68 倍，双方在该处都剧烈起伏。
5. **高质量端（5–62 GeV）残差 0.69–0.91**：叠加了 Fix 3、参考曲线末段数字化误差。
6. **产生侧简化**：D 介子未实现（D/B ≈ 5e-9，已用数量级检查满足 prompt）；母样本是 HardQCD bb̄ 而非 prompt 要求的 SoftQCD:inelastic；Higgs 硬产生是纯 Pythia8 LO 而非 MG5+Pythia8（子过程配比偏差 ≤1.3%，已量化）。
7. **s_cut = 2.3（90% CL）**：prompt.md 写的是 s = 3（95%）。按用户决定用 2.3；`_s3` 结果一并保留。

`work/widths/scalar_widths.py` 现在只含 arXiv:1809.01876 的东西：

### 7.4 分支比对照图

`work/analysis/plot_br_validation.py` → `outputs/figures/br_validation.png`：逐通道把
我们的 Winkler 分支比和参考表并排画。可见：轻子三道几乎重合；**ππ/KK 用的是 Winkler 的数字化曲线，而这条曲线本身就是同位旋标量率**
（论文第 200 行：「the Clebsch-Gordan coefficient occurring in the isoscalar projection of the ππ state
has been absorbed into the definition of F」，印出的公式里也带着 7/9、7/9、2/9 三个权重），
即 π⁺π⁻+π⁰π⁰ 与 K⁺K⁻+K⁰K̄⁰；参考表的列是**单一电荷态**（π⁺π⁻、K⁺K⁻），所以那两格差一个常因子
（实测：K K 比 2.00、ππ 比 1.5，正是 1+1 与 1+1/2）；
**4π 在 1–2 GeV 我们明显偏低**（参考有真实的 2π⁺2π⁻ / π⁺π⁻2π⁰，我们是单一项）；
**gg 在 2–3 GeV 我们低约一倍**（LO vs NLO）；5 GeV 以上 ss/cc 因质量方案不同而分叉。

### 7.5 结论：模型差异 vs 实现错误

- **实现层**：宽度逐通道对 Winkler 的比值 1.0000（m_S < 2 GeV），锚点全部对上；
- **验证层**：管线能复现参考到 ~19%（中位 1.08）；
- **模型差异层**：Winkler 与 Boiarska/SensCalc 的差别（NLO gg、跑动质量、真实 4π）在 1.2–3 GeV 是 1.2–1.8 倍，
  在 5–30 GeV 是 0.5–0.7 倍 —— 这是物理模型的不确定度，应当作为系统误差报告，而不是继续调代码。
