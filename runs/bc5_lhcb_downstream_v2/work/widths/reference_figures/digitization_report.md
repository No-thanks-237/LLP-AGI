## General caveats

* All coordinates are PDF user-space points of the single page of each file (origin top-left, y increasing downwards, 72 pt = 1 inch); extraction uses the vector path centre lines, so stroke width does not bias the values.
* Curves clipped by the axis frame keep the clipped (frame) value at their end points; those points are true plotted values but are only bounds on the underlying model.
* Near-vertical parts of a curve give several values at (almost) the same mass; the CSVs are sorted by mass but are NOT single-valued functions there.
* Ticks are read from vector strokes and tick labels from the text layer; the quoted residual is the max |fitted - measured| tick position in PDF points.
