## 1. 产生谱 vs FORESEE（"pp 对撞产生粒子谱"）

目的: 在进入模型计算前，先确认母样本的 pp 产生谱与 FORESEE 的已验证前向谱一致。

方法: 用本 run 的 B 强子样本（Pythia 8.316, pp 13 TeV, 800k 事例, σ(bb̄)=560 μb）和
π/K minbias 样本，按 FORESEE 的 (log10 θ, log10 p) 分 bin（20 bin/decade, 前向半球）
重建 dσ/bin，与 FORESEE 公开谱（files/hadrons/13.6TeV/Pythia8, 已下载到
references/tools/FORESEE/files/hadrons/）逐 bin 比较。

结果（B0/B0bar/B+/B-，我们的 13 TeV vs FORESEE Pythia8 13.6 TeV）:
  * 前向总截面: 我们 475.0 μb vs FORESEE 318.9 μb（比值 1.49）。
    分解: 13→13.6 TeV 的能量标度 +4.6%；同能量下 FORESEE 的 Pythia8 文件隐含
    σ(bb̄)=378 μb（LO 归一），而我们的 560 μb 用测量值 → 同能量比 1.55，除以 1.046
    正好给出观测的 1.49。用 FORESEE 自己的 NLO-P8（其 2HDM_H 模型实际使用的谱）比较
    则为 1.056（同能量差 10%，位于 FORESEE Max/Min 包络 0.71–1.42 与 LHCb 560±80 μb 内）。
  * 形状: bin 比值（去全局归一）中位 0.976, RMS 13.1%, 89% 的 bin 在 ±20% 内；
    在 LHCb 母粒子接受度区间 1.5<η<5.5（占总截面 66%）的**积分**形状一致到 **0.4%**
    （注意：这只是接受度内的积分一致，逐 bin 精度是 RMS 13.1%；不能当成全形状精度）；
    唯一系统性倾斜在最前向尾部 η>5.5（-10%，在探测器接受度之外，且其中约 3% 可由
    能量标度解释）。
  * π/K（次要）: 我们的样本只存 prompt status-91/92 强子，FORESEE 谱含衰变贡献
    （π+ 803.8 vs 1361.6 mb 等），定义不同，不作归一比较；FORESEE 自己也推荐轻强子用
    EPOS/SIBYLL 而非 Pythia。

结论: 在 LHCb 接受度内**没有形状偏差**；1.49 的整体归一差是 LO vs 测量/NLO 的 σ(bb̄)
约定差，已在图中分解验证。图: outputs/figures/production/（总览 + 每个粒子单独一张，
  outputs/figures/production/spectrum_*.{png,pdf}；数值表 outputs/data/spectrum_vs_foresee_numbers.csv）；
脚本 work/analysis/spectrum_foresee.py；详见 logs/spectrum_vs_foresee.md。

## 5. "大 MC 误差"问题：根因、修复与残余（2026-10-26 第二轮，结论已修正）

**现象**: 短寿交点处 s 的事例级 MC 误差 50-100%（长寿边只有 ~3.5%）。

**第一次诊断（错误，已作废）**: 曾认为方差来自母样本的"极端高能尾部"（B pz 1-4 TeV）。
分层抽样（尾部普查 + Horvitz-Thompson 权重）确实把长寿边做稳了，但短寿交点的 s 级误差
仍为 50-100%，且不同分层方案给出的 s 相差数量级——说明诊断不完整。

**正确根因**: 在短寿交点处 H 的衰变长度远小于 1 m，H 只可能在**母粒子 B 恰好飞到
1-2.5 m 衰变窗内**时被探测到：P(B 飞 >1 m) = exp(-1/λ_B)，λ_B = (pz_B/m_B)cτ_B ≈ 0.1-0.3 m
→ 1e-3…1e-5。旧实现**抽样**母粒子衰变顶点 z0；17293 个 B 母粒子中 z0 落入窗口的期望只有
O(1) 个，而且还要与"该 H 的衰变产物能通过接受度"同时发生。于是估计量虽然无偏，但单次实现
远低于期望（重尾），并且**报告的 50-100% MC 误差本身也低估了真实不确定度**（控制实验：
解析方差公式在重尾情形低约 1.5 倍）。把每个候选的衰变抽样数 ndecay 从 10 提到 30/100
完全无效（0.598→0.602），因为方差来自顶点抽样而不是衰变产物抽样。

**修复（Rao-Blackwell 化）**: 把母粒子衰变位置解析积分掉：

    p = ∫ dz A(z) W(z),  W(z) = C [ exp(-z/λ_P) - exp(-α z) ],  C = α/(α λ_P - 1),
    α = m_H/(cτ_H pz_H),  λ_P = (pz_P/m_P) cτ_P  （带符号）

  * λ_P > 0（前向母粒子）: 用上式；λ_P < 0（背向母粒子，H 仍可能前向但很软）:
    p = p_prompt/(1 + α|λ_P|)；λ_P = 0（瞬时母粒子，如 SM Higgs）: p = p_prompt（与旧
    p_window 在 z0=0 处逐位相同）。
  * 响应 A(z) 从产生点计算（对贡献区间 z0 ≤ 2.5 m 的横向位移 ≤ cm，可忽略）。
  * α λ_P ≈ 1 是可去奇点（W → α z e^{-αz}），用 2e-3 的相对平移稳定闭式，误差 O(2e-3)。

**验证**（work/analysis/temp 下的脚本 + logs/）:
  1. 闭式 vs 对 z0 的暴力平均：主导事例（α λ_P = 120-160）符合到 **0.1-0.8%**；
     一般参数扫掠在 MC 精确的区间内符合 <0.2%；prompt 极限与旧 p_window 逐位相同。
  2. 全样本重要性抽样（均匀 z0 提案）交叉检查：与解析总和无偏一致（差异在 IS 误差内）。
  3. 长寿边（对 λ_P 不敏感）与上一版一致到 ±1%（交点位置 ≤1.5%），证明修复没有破坏物理。
  4. 响应表 v3 记录每 history 的 λ_P（work/analysis/response_table.py）。

**后果（重要）**: 修正后短寿交点**消失**——在 tanβ=5…10 处 s 已经比阈值大 1e3-1e6 倍
（例：mH=4.18 GeV, tanβ=5: s=2.5e4；mH=1 GeV, tanβ=5: s=3.0e5），s(tanβ) 从 tanβ=5 到
长寿边一直高于 s90。因此：
  * 排除区 = 扫描下界 tanβ=5 以上、长寿边以下**全部** tanβ；低 tanβ 侧**没有被本次分析
    闭合**（真正的闭合点在 tanβ<5，或由 EFT 有效性 Br(B→X_sH)<0.1 给出）。
  * 此前 v2 版本里 tanβ=5-43 的"短寿交点"是顶点抽样不足造成的**伪迹**，不应再引用。
  * 残差 MC 误差（低 tanβ 各点 s）：30-45%，来自母粒子能量/方向的高 pz 尾部；在重尾情形
    建议把报告的 ds 乘 ~1.5 作为保守误差。
  * 长寿边（物理上限）不变：25 fb^-1 为 22.0-358.0，300 fb^-1 为 30.0-488.9（与上一版差 ≤1%）。

**结论/建议**: 程序的这一缺陷已修复（响应表 v3）。若要把低 tanβ 侧变成可引用的物理边界，
仍需要专门的高 pz b 样本（10-30M 事例）把 30-45% 压到 ~10%；但该区域本来就在
Br(B→X_sH)≳0.1 的 EFT 失效区，优先级低于已有的长寿边结果。

### 8.2 母粒子位置积分的横向位移近似（审计"需直接实验"项）

近似内容：A(z) 从**产生顶点**计算，而真实衰变点在 v0+z0*dir。位移量
Delta_r = z0 (pT/pz)_parent，而积分中有效的 z0 满足 z0 <~ min(2.5 m, 几倍 lam_P)：
* B 组：TeV 级 B 的 lam_P ~ 0.1-0.3 m，有效 z0 <~ 1 m，pT/pz ~ 1e-4 -> Delta_r <~ 0.1 mm；
* K/pi 组：lam_P ~ 100-1000 m，但信号要求母粒子在 z<~2.5 m 内衰变，pT/pz ~ 0.005-0.01 -> Delta_r <~ 2 cm；
* h 组：产生顶点即衰变点，位移 = 0。
探测器接受度在 ~1 m 尺度上变化，故 2 cm 位移对应的相对变化 <~2%，且 inelastic 在长寿边处是次要成分。
数值检验：用公共随机数（同一批衰变抽样）比较"从产生点"与"从位移点"的 A(z)，逐候选无法分辨
（A 本身的 ndecay=10 统计噪声 ~10-30%）；二维（z0 网格 x 位移）检验的统计精度同样受限于 A 的噪声。
结论：这是有界近似（<~2% 对 inelastic 分量），但未做高统计的二维验收——已列入限制。

### 8.3 碰撞级 OR 的无偏性措辞（审计 F7 第 2 点）

正确表述：抽样是按母粒子做的，每个母粒子带精确逆包含概率权重；**逐母粒子**的期望无偏。
碰撞级 OR 是非线性运算，把 HT 权重放在 OR 内部不保证严格无偏，偏差为 O(q^2)（q = 单个母粒子
在一个碰撞内产生可见信号的联合概率）。长寿边处 q ~ 1e-8（产生 BR 还要再乘），偏差可忽略；
低 tanb 高产生率区域 q 可能不小，但该区域本来就在 EFT 失效区且已远高于阈值。本轮未发现它对
名义边界有可见影响，文档已按此收窄。
