## 三、9 项代码指控的逐条核查

### 3.1 mixing 与 quartic 产生被乘同一混合角 —— **成立**

| 证据 | 内容 |
| --- | --- |
| 代码 | `run_scan.py:243` quartic 标量以 `wq`（quartic 分支比，与 θ² 无关）加入 |
| 代码 | `run_scan.py:366` `out['B'] = ... * epsB * theta2`，对整个 B 道统一乘 θ² |
| 论文 | Boiarska：quartic 产生正比于 α²，与混合角 θ 无关 |

**物理判断正确。** mixing 分支比 ∝ θ²，quartic ∝ α²（固定），二者必须分开加权。

补充：审计指出的“先按衰变历史平均、再对完整碰撞事件做 OR”也是正确的概率记账。当前实现对每个标量各乘一次分支比再做 OR，`b=0.01, p₁=p₂=0.5` 时给出 0.009975，正确值 0.0075。

### 3.2 响应平均条件化在“有带电产物”上 —— **成立**

`bc5_lib.py:399–409`：
```python
if not rest:
    continue          # 空衰变被跳过
...
nused += 1
...
return tot / nused     # 除以非空次数，而非抽样次数
```

**物理判断正确。** 按总分支比抽样后，无可见产物的衰变必须以零响应留在分母；当前算的是条件效率，系统性高估。审计给出的非空比例 0.70–0.98（随质量变化）也合理。

### 3.3 Higgs 子粒子按相邻行配对 —— **成立**

`run_scan.py:380–383`：`pk = p[sel]; pk = pk[:n2].reshape(-1, 2)`。

`add()` 在 `decay_vertex_and_selection` 中丢弃 η 范围外的 S，故存活行不保证属于同一 Higgs；奇数行末位还会被丢弃。**代码事实正确，应按 `ev` 分组。**

审计同时说明“该反例不表示整条边界损失近一半”——这个限定是正确的，长寿命极限下交叉项小。

### 3.4 MC 标准误被额外除以抽样数 —— **成立**

`run_scan.py:389`：`seH = sqrt(varH/n_smp) * scale / n_gen_higgs * RECO_EFF`，其中 `scale = n_tot/n_smp`。

正确式应为 $\mathrm{SE}=0.4\,(n_{tot}/n_{gen})\sqrt{\widehat{\mathrm{Var}}(o)/n_{smp}}$。当前多除一个 `n_smp`，默认 1200 时误差被压低约 1200 倍。**公式判断正确。**

### 3.5 边界误差带两侧写反 —— **成立（但仅影响误差带）**

`make_curves.py:112–113`：`lo_e` 用 `max(cr_m)-max(cr_p)`，`hi_e` 用 `min(...)`。而 `lo` 是长寿命边（小 θ²）、`hi` 是短寿命边（大 θ²），`max` 取到的是短寿命侧。**确认写反。**

影响范围：只影响误差条，不影响中央曲线。数值量级 ~1e-4。

### 3.6 母粒子飞行长度米/毫米混用 —— **成立**

`run_scan.py:140–143`：`disp = (p3/m)*ctau*u`，其中 `ctau = HBAR_C/GAM` 单位为**米**；但 `mes['x']` 来自样本，单位是**毫米**，直接相加。

### 3.7 强子化库质量索引串档 —— **成立**

### 7.1 概率记账重构（3.1 + 3.3 + 3.4）

引入三层结构：**标量行 → 衰变历史 → 母粒子 → 碰撞**。

`run_scan.py` 的每一行新增三个字段：

| 字段 | 含义 |
| --- | --- |
| `par` | 母粒子编号（同一母粒子的所有行共享） |
| `hid` | 该母粒子的衰变历史编号（同一母粒子的历史互斥） |
| `kq` | 1.0 表示该历史速率含 θ²（mixing），0.0 表示不含（quartic、h→SS） |

新函数 `channel_efficiency` 按顺序做三件事：

$$
o_h = 1-\prod_{\text{rows}\in h}(1-w_{h}p\theta^{2k_q}),\qquad
p_{\text{par}}=\sum_h o_h,\qquad
o_{\rm ev}=1-\prod_{\text{par}\in\rm ev}(1-p_{\rm par})
$$

$$
\epsilon = 0.4\,\frac{n_{\rm tot}}{n_{\rm smp}n_{\rm gen}}\sum_{\rm ev}o_{\rm ev},\qquad
\mathrm{SE}=0.4\,\frac{n_{\rm tot}}{n_{\rm smp}n_{\rm gen}}\sqrt{n_{\rm coll}\widehat{\rm Var}(o_{\rm ev})}
