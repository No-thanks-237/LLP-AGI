# FORESEE 2HDM_H reference subset

This directory contains only `Models/2HDM_H/` (5.4 MB) copied from the FORESEE repository
that was downloaded during the 2HDM light-H run.  The full checkout (1.8 GB) was removed from
`temp/` during workspace cleanup; only the parts used for validation are kept here:

* `Models/2HDM_H/model/br/*.txt`, `model/ctau.txt` — decay branching ratios / lifetime tables
  generated by the authors with the same Light_scalar_decay program (reference for
  `runs/20261025_1325_UTC_2HDM_lightH_lhcb_downstream/logs/decay_validation.md`);
* `Models/2HDM_H/2HDM_H.ipynb` — the authors' B -> X_s H production formula used in the
  production cross-check (`logs/model_audit.md`);
* the reach-figure PDFs used for the optional comparison (`comparison_paper_reach.png`).

Original code: https://github.com/KlingFelix/FORESEE (MIT licence, see LICENSE.md).
The author code zip is kept at `references/model/Light_scalar_decay_Combined_Code.zip`.

## Forward hadron spectra added for the pp-sample cross-check (2026-10-26)

The forward spectra of `files/hadrons/<E>TeV/<gen>/<gen>_<E>TeV_<pid>.txt` were downloaded
(60 files, 22 MB) to cross-check our Pythia 8.316 pp samples against the published
FORESEE spectra (see `runs/20261025_1325_UTC_2HDM_lightH_lhcb_downstream/logs/spectrum_vs_foresee.md`):

* `13.6TeV/Pythia8/`    pi+-, K+-, B0/B0bar, B+-, Bs/Bsbar, Bc/Bcbar (12 files) - main reference;
* `14TeV/Pythia8/`      same B species (8 files) - 13.6 -> 14 TeV energy-scaling check;
* `13.6TeV/NLO-P8/`, `13.6TeV/NLO-P8-Max/`, `13.6TeV/NLO-P8-Min/` - the beauty family the
  authors' own `Models/2HDM_H/2HDM_H.ipynb` uses for B -> X_s H (10 + 4 + 4 files);
* `14TeV/NLO-P8/` (8 B species) - energy-scaling cross-check;
* `13.6TeV/EPOSLHC/`, `13.6TeV/SIBYLL/` - pi+-/K+- generator spread (8 files).

Provenance: raw GitHub URLs
`https://raw.githubusercontent.com/KlingFelix/FORESEE/main/files/hadrons/<E>TeV/<gen>/<gen>_<E>TeV_<pid>.txt`;
sha256 of every file is in `files/hadrons/MANIFEST.sha256`.

Format: three columns `log10(theta/rad)  log10(p/GeV)  dsigma[pb/bin]`, 20 bins/decade, forward
hemisphere only (theta < 90 deg).  The `# Normalization:` header equals the sum of the bin
weights, i.e. the forward-hemisphere cross section of that species (it is *not* the
total pp cross section).  The Pythia8 spectra were made with Pythia 8 + Monash tune at
13.6 TeV; the NLO-P8 family carries the NLO bbbar normalisation (its forward B0+B+
cross section is ~1.40x the Pythia8 one, and Max/Min span another factor 0.74-1.49).
Our 560-ub-normalised 13 TeV B sample sits inside that envelope.

The downloaded files are the only parts of the FORESEE repository added; the
`Models/2HDM_H/` subset and code reference above are unchanged.
